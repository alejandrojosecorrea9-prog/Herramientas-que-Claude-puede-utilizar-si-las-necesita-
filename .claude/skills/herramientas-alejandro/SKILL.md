# Herramientas de Alejandro

1. Lee `README.md` en la raíz del repositorio y elige la herramienta que encaje con la tarea.
2. Clónala con `git clone --depth 1 <link>` en una carpeta nueva (o corre `bash scripts/clonar-todo.sh`) y lee su README.
3. Haz la tarea sin preguntar dónde buscar. Entrega el resultado por el chat.
4. Si Alejandro pasa un repo nuevo, agrégalo al README y haz commit y push.
