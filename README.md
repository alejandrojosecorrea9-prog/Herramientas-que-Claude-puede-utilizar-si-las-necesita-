# Herramientas que Claude puede utilizar

Repositorios de otras personas que Alejandro quiere que Claude use cuando una tarea lo necesite, sin que él diga dónde buscar. Cada uno se descarga desde su repo original (así queda actualizado y con su licencia).

| Herramienta | Link | Para qué sirve |
|---|---|---|
| Eigent | https://github.com/eigent-ai/eigent.git | App de escritorio multiagente (Electron). Referencia para organizar el espacio de trabajo y flujos de varios agentes. Necesita computador y claves de modelo. |
| agent-browser | https://github.com/vercel-labs/agent-browser.git | Navegador controlado por comandos para agentes: abrir páginas, leerlas, hacer clic y llenar formularios. Para automatizaciones web, capturas y pruebas de pantallas. |
