# Herramientas de Alejandro (para Claude Code)

Este repositorio es el índice de herramientas que Alejandro quiere que Claude use sin que él diga dónde buscar.

- Lee `README.md`: lista cada herramienta con su link y para qué sirve (grupos: Zula, video, generales).
- Cuando Alejandro pida una tarea, elige la herramienta que encaje, clónala con `git clone --depth 1 <link>` en una carpeta nueva y lee su README antes de usarla.
- Para bajar todas de una vez: `bash scripts/clonar-todo.sh` (las deja en `herramientas/`).
- No le preguntes dónde buscar. Si ninguna sirve, busca en otras partes y hazlo.
- Alejandro no tiene computador: todo se le entrega por el chat.
- Cada repo nuevo que pase se agrega al README (grupo Zula, video o generales), con commit y push.
